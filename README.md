# بوت المساعد الدراسي الطبي 🩺

بوت تيليجرام يلخص المحاضرات الطبية، يولّد أسئلة مراجعة، ويشرح المصطلحات — بالعربي.

## 1. المتطلبات

- Python 3.10 أو أحدث
- توكن بوت من BotFather
- مفتاح Anthropic API (من https://console.anthropic.com)

## 2. تسوي البوت في BotFather (لو ما سويته)

1. افتح تيليجرام، ابحث عن `@BotFather`
2. أرسل `/newbot` واتبع التعليمات (اسم + username ينتهي بـ bot)
3. راح يعطيك توكن شكله كذا: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`

## 3. التثبيت

```bash
cd med-study-bot
python -m venv venv
source venv/bin/activate   # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

## 4. متغيرات البيئة

سوّ ملف `.env` (أو صدّر المتغيرات مباشرة بالترمنال):

```bash
export TELEGRAM_BOT_TOKEN="التوكن اللي أخذته من BotFather"
export ANTHROPIC_API_KEY="مفتاح Anthropic API"
```

لو تبي تستخدم ملف `.env` تلقائيًا، ثبّت `python-dotenv` وأضف بأول `bot.py`:
```python
from dotenv import load_dotenv
load_dotenv()
```

## 5. التشغيل

```bash
python bot.py
```

لو ظهرت رسالة "Bot starting..." يعني اشتغل. جرب تفتح تيليجرام وترسل `/start` للبوت.

## 6. الأوامر المتاحة

| الأمر | الوظيفة |
|---|---|
| `/start` | رسالة ترحيب وشرح |
| أرسل ملف PDF أو نص | تلخيص تلقائي |
| `/quiz` | يولّد 5 أسئلة مراجعة من آخر محتوى أرسلته |
| `/explain <مصطلح>` | يشرح مصطلح طبي |
| `/upgrade` | معلومات الترقية للنسخة المدفوعة |

## 7. نموذج الربح المبني بالكود

- 5 طلبات مجانية يوميًا لكل مستخدم (تقدر تغيّرها من `FREE_DAILY_LIMIT` في bot.py)
- تفعيل الاشتراك حاليًا **يدوي**: بعد ما يدفع المستخدم (تحويل بنكي/STC Pay)، تشغّل:

```python
from db import Database
db = Database("bot_data.db")
db.set_premium(USER_ID, True)
```

`USER_ID` تقدر تشوفه من رسائل تيليجرام أو من `update.effective_user.id` (أضف طباعته مؤقتًا للتجربة).

## 8. الخطوة القادمة: دعم الصور (اختياري)

حاليًا البوت يدعم PDF ونص مباشر بس. لو تبي دعم صور المحاضرات (لقطات شاشة مثلاً)، أسهل طريقة إنك ترسل الصورة مباشرة لـ Claude Vision بدل استخراج نص عبر OCR تقليدي. قله لي إذا تبي هالميزة وبضيفها.

## 9. النشر (Deployment)

للتشغيل المستمر 24/7 بدون ما يكون جهازك مفتوح، تقدر تنشره على:
- **Railway.app** أو **Render.com** (فيهم خطط مجانية بسيطة تكفي للبداية)
- VPS رخيص (Hetzner, DigitalOcean)

لو تبي، أقدر أعطيك خطوات النشر بالتفصيل على أي منصة تختارها.

## 10. بوابة الدفع الفعلية (بدل اليدوي)

لما يكبر عدد المستخدمين وتصير العملية اليدوية متعبة، اربط بوابة دفع زي:
- **STC Pay** أو **PayTabs** (تدعم السوق السعودي مباشرة)
- **Stripe** (لو تبي تستهدف جمهور دولي أيضًا)

البوابة ترسل webhook لما يدفع المستخدم، وتقدر تربطه بدالة `db.set_premium()` تلقائيًا بدل التفعيل اليدوي.
